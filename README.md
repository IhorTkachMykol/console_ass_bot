# console_ass_bot
Сonsole assistant bot that will recognize commands entered from the keyboard and respond according to the input command.

In this assignment, I will focus on the interface of the bot itself. The simplest and most convenient interface at the initial stage of development is a CLI (Command Line Interface) application. A CLI is relatively easy to implement.
